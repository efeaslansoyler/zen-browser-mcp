# Icon sources

The agent logos are trademarks of their owners and are used only to show which agent a
session belongs to.

- `claude.svg`, `antigravity.svg`, `opencode.svg`: from https://thesvg.org (`opencode.svg`
  recolored from `currentColor` to a fixed gray so it shows in light and dark menus).
- `codex.svg`: drawn for this project after the Codex app icon (a cloud with a terminal
  prompt). Codex is a trademark of OpenAI.
- `multi.svg`: drawn for this project.
